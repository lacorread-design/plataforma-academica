## Descripción

La Plataforma Académica Básica es un proyecto orientado a representar de manera sencilla un entorno académico. Su propósito es servir como base para la gestión y presentación de información relacionada con actividades académicas.

El proyecto se desarrolla como una práctica de trabajo individual utilizando Git y GitHub, aplicando el uso de ramas, commits, repositorios remotos y pull requests.

## Tecnologías

* HTML
* CSS
* Git
* GitHub
